# Money_Tracker.AI

Money_Tracker.AI is a Python-based expense tracker project that helps users manage their income, expenses, and savings in a simple way.

## Features

- Add and track daily expenses
- Manage income and spending
- View total balance
- Organize expenses by category
- Simple and beginner-friendly project

## Tech Stack

- Python
